This repository contains all practicum assignments for the **Natural Language Processing (NLP)** course - Spring Semester 2026.

Each practicum is organized in its own folder, containing a Jupyter Notebook (`.ipynb`) and any necessary resources (datasets, supplementary files, etc.).

## 🛠 Requirements

To run the notebooks in this repository, you need:

- **Python** 3.9 or higher
- **Jupyter Notebook** or **JupyterLab**
- Required Python libraries (see details in each notebook)
